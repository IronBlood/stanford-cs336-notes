# Lecture 13: Data (Sources, Datasets)

## Keywords

- Web crawling
- Data provenance
- Licensing and copyright
- Pretraining corpora
- Quality filtering

## Summary

The lecture traces pretraining data from live internet services to usable corpora. Crawling and bulk downloads face practical limits involving dynamic pages, authentication, server load, access restrictions, and provenance. A discussion of licensing and copyright frames the social context of collection. Common Crawl, Wikipedia, GitHub, and arXiv illustrate different sources and transformation requirements. A survey of datasets follows changing collection recipes, including curated mixtures, increasingly large web corpora, classifier-based filtering, synthetic transformations, and permissively licensed collections. The central point is that data does not arrive ready for training: source selection, extraction, filtering, and documentation shape both model capabilities and downstream concerns.
